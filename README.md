# Weather App

A responsive weather application built using HTML, CSS, and JavaScript that displays real-time weather information for any city using the World Weather Online API.

## Features

* Search weather by city name
* Real-time temperature display
* Current weather condition with icons
* Live local time display
* Current date and day
* Humidity and weather details
* Hourly weather forecast
* Horizontally scrollable forecast cards
* Responsive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* World Weather Online API
* Fetch API

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Pratheeksha27032007/Weather-api.git
```

2. Navigate to the project folder:

```bash
cd Weather-api
```

3. Open `index.html` in your browser.

## API Setup

This project uses the World Weather Online API.

1. Create an account at:
   https://www.worldweatheronline.com/

2. Generate an API key.

3. Replace the API key in `script.js`:

```javascript
const key = "YOUR_API_KEY";
```
